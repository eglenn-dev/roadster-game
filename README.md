# Tesla Roadster Game

This was a fun experiment so I could see what Opus 5.5 was capable of without heavy instruction and guidance. No AGENTS.md, no skills, just a blank repository.

I opened a empty folder, started T3 Code in it, and gave it the prompt below, and that was it. No follow up prompt, no encouragement. It did everything you see in 54 minutes. I even gave it the option to ask questions, but it never did.

## Stats:

- Model: Claude Opus 5.5 on high effort
- Harness: Claude Code via [T3 Code](https://t3.codes/)
- Time: 54 minutes
- Prompt:

> This is a blank project. I want you to make an in browser game based on the Tesla Roadster event from yesterday. I want the in game car to meet all of the specs that the actual car can. I think an interactive car driving simulator where I can drive the car through the same demos that they gave at the event yesterday would be best. I want this to be as well optimized for browsers as it could be so use WebGPU where needed and make it the best quality browser game possible, and make it run at at least 30 fps, but probably more. Ask me questions as needed, or just take off and start going.
